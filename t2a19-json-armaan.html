What is JSON?

JSON stands for JavaScript Object Notation. It is used to store and send information between websites and programs. This project uses fetch to get information from an API and display it on my webpage.

Thanks for checking out my JSON project!


My JSON Research

JSON is a format that stores information using key and value pairs. It is commonly used when websites communicate with other websites.

The fetch command gets information from an online API. The response.json() command changes the information into JavaScript so I can use it in my code.

The JSON.stringify() command changes the information back into readable text so I can display it on my webpage.
