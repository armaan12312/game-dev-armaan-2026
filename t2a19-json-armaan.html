How to use my JSON Animal Viewer

  • Choose an animal from the dropdown menu.
  • Click Get Animal to see a random picture.
  • Look at the JSON information underneath.
  • Click Random Animal to choose a surprise animal.
  • Try different animals and compare their JSON data!

What I Learned

I learned that JSON stands for JavaScript Object Notation. It is used to store and transfer information between websites and servers.

I also learned how to use fetch() to get information from APIs on the internet.

My favourite part of this project is being able to get random animal pictures using different APIs!
