Instructions t2a17-Hackbrowser

Welcome to my browser hacking project! This page lets you explore different browser objects and see what information they contain.

Use the buttons below to check out different objects. The results will appear in the large text box. You can also sort the results alphabetically.

Different browsers may show different results. This is a way to learn how browsers work and how JavaScript can access their information.

My Thoughts

I learned that JavaScript can access different browser objects like window, document, navigator and screen. Each object has its own properties and methods.

I also learned that different browsers can show different information depending on what they support.

My favourite part of this project is being able to click buttons and see information about the browser.
