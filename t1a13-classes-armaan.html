Classes act as blueprints for creating objects. Key concepts include:

  • Properties: Variables attached to the class inside the constructor().
  • Methods: Functions defined inside the class that perform actions using those properties.
  • Inheritance (`extends`): Allows one class to inherit features from another parent class.
