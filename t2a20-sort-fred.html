Why is sorting useful?

Sorting helps organize numbers so they are easier to read and compare. This program uses bubble sort to move numbers into the correct order.

What I Learned

I learned how to use arrays to store numbers and how loops can compare different values.

I also learned how bubble sort works by comparing two numbers and switching them if they are in the wrong order.

My favourite part of this project is being able to sort numbers in different ways and calculate statistics.
